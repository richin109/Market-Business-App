## Slice Contract

Check a slice only when all of these hold:

- **Scope:** only the named context/interfaces.
- **Dependencies:** prior migrations/contracts/decisions/synthetic fixtures and predecessor's executable local profile (entry points, migrations, candidate checks where applicable) must pass before next MVP. Private/live approval gates are production-only and never replace local checks.
- **Acceptance:** focused synthetic/mock tests; Playwright for changed UI.
- **Receipt-derived work:** prove accounting/stock/reporting with committed synthetic fixtures, including RM-025 5→10→15 replay; only newly approved occurrences create downstream facts. RM-024 private-corpus evaluation is a separately authorized production gate; it never blocks synthetic MVP profiles. If authorized, evaluate reviewed annotations only in isolation; unannotated cases stay held. Keep originals/expectations/identifiable logs out of git/CI; retain approved redacted aggregates only.
- **Traceability:** link manifest IDs or focused test in `03-current-slice.md`; planned rows are not evidence.
- **Schema:** backend-neutral SQLAlchemy + reviewed Alembic; test fresh/prior PG upgrades, synthetic rows, guarded downgrade/re-upgrade, ORM parity. No file DBs or skipped DB gates.
- **Validation:** follow [fast-test contract](00-overview.md#fast-test-development-contract-all-stages): focused `test-dev` pytest, Ruff, mypy, full `test-dev`; rebuild only as required. Candidate certification requires rebuilt, unmounted `test`; mounted results are not release evidence.
- **Stop:** unapproved decision, user action, missing contract, fixture conflict, failed migration, or undiagnosable test. Never infer policy.
- **Evidence:** record commands/results, rebuild reason, mounted/candidate context, commit/digest, skips, remaining work in `03-current-slice.md`; preserve candidate manifest commands.

## Agent Operating Rule

The agent advances to the next row only when the current row's acceptance tests and validation evidence pass. A later MVP may be designed in this document, but it must not be implemented until its prerequisites and owner decisions are recorded in `03-current-slice.md`. The agent must never convert a proposed default into an approved business rule or use a planned manifest ID as evidence.
